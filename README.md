# Lua Vermelha — Landing/Catálogo de Sexshop

MVP front-end em HTML, CSS e JavaScript para iniciar um e-commerce adulto com:

- Verificação de idade (+18) com persistência em `localStorage`
- Catálogo em destaque com filtro por categorias
- Layout moderno com foco em privacidade e discrição

## Como executar

```bash
python3 -m http.server 4173
```

Acesse `http://localhost:4173`.
